🚀 Praticando JavaScript — Divisão com Validação
📌 Sobre o projeto
Este projeto foi desenvolvido a partir de um exercício prático de JavaScript, com o objetivo de aplicar conceitos fundamentais de lógica de programação, funções, operações matemáticas e validação de dados.
O exercício original foi ampliado com o apoio de Inteligência Artificial, transformando uma atividade simples em um ambiente interativo de aprendizagem.
🎯 Funcionalidades
Simulação dos comandos prompt() e alert().
Calculadora interativa com operações de divisão.
Validação de entradas numéricas.
Tratamento de divisão por zero.
Histórico de execuções.
Depurador visual com execução passo a passo.
Visualização matemática da divisão.
Editor de código para experimentação.
Desafios práticos de JavaScript.
Quiz interativo para fixação dojavascript-divisao-validacao-interativa conhecimento.
Temas claro e escuro.
💻 Tecnologias utilizadas
JavaScript
HTML5
CSS3
TypeScript
React
IA Generativa como apoio ao desenvolvimento.
📚 Conceitos praticados
Variáveis e constantes (const).
Conversão de dados (parseFloat).
Validação numérica (isNaN).
Estruturas condicionais (if/else).
Funções e parâmetros.
Retorno de valores (return).
Operadores matemáticos.
Comparação estrita (===).
Tratamento de erros e validações.
🤖 Desenvolvimento com Inteligência Artificial
Durante o desenvolvimento, utilizei o Gemini 3.8 Flash como ferramenta de apoio para expandir o exercício original, explorar possibilidades de implementação e construir recursos interativos de aprendizagem.
A experiência permitiu praticar programação e compreender melhor como a IA pode auxiliar no processo de desenvolvimento de software.
🎓 Objetivo de aprendizagem
Consolidar conhecimentos em JavaScript e desenvolver habilidades práticas em programação, lógica computacional e desenvolvimento de interfaces interativas.
